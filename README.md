# Receita+
Sistema de receitas com 550 receitas, busca, filtros, favoritos e página de detalhes.

## Publicar na Vercel
1. Crie uma conta em https://vercel.com/
2. Crie um novo projeto.
3. Envie estes quatro arquivos: `index.html`, `style.css`, `app.js` e `recipes.js`.
4. A Vercel publica o site automaticamente.

Não é necessário banco de dados para esta versão. Os favoritos ficam salvos no navegador do usuário.
